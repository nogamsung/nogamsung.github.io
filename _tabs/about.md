안녕하세요. 프로덕트 엔지니어 **안검성**입니다.

서비스를 만들고 운영하면서 마주친 문제와, 그때 어떤 선택을 했고 결과가 어땠는지를 이 블로그에 기록합니다.

## 하는 일

2023년부터 2025년까지 여행 플랫폼 회사에서 Spring Boot 기반 백엔드를 개발했습니다.
JPA와 Querydsl 성능 개선, Redis 분산 락, Kong API Gateway 도입 같은 이 블로그 초반의 글들은 그때 겪은 일들입니다.

2025년부터는 제조 회사에서 프로덕트 엔지니어로 일하고 있습니다.
사내 플랫폼을 처음부터 설계하고, 배포와 운영까지 책임집니다.
최근 글들은 그 과정에서 내린 결정과 그 이유의 기록입니다.

## 다루는 주제

- **백엔드**: Spring Boot·JPA 성능, 동시성 제어, 서킷브레이커, 모듈 구조
- **인증과 보안**: JWT 세션 설계, 권한 즉시 반영, 쿠키와 BFF
- **프론트엔드와 실시간**: Next.js 운영, WebSocket 재연결, 안읽음 집계
- **인프라와 배포**: 온프레미스 무중단 배포(Kamal), API Gateway, 컨테이너
- **AI 네이티브 개발**: 코딩 에이전트 도입과 하네스, 제품 안의 LLM

## 글을 쓰는 방식

- **문제에서 시작합니다.** 무엇이 왜 문제였는지부터 적습니다.
- **선택의 이유를 남깁니다.** 어떤 선택지를 비교했고, 왜 그쪽을 골랐는지 적습니다.
- **따라 할 수 있게 씁니다.** 실제로 적용한 코드와 설정, 측정한 결과를 함께 남깁니다.

정답이라기보다 그 시점에 내린 결정이라, 더 나은 방법을 아신다면 알려주시면 감사하겠습니다.
